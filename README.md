# AI Fashion Image Generation with ComfyUI

Proyecto de generación de imágenes de moda con IA realizado para una marca de ropa.

## Descripción
Este proyecto consiste en transformar imágenes de artículos de ropa extraídas de una tienda online en imágenes promocionales con modelos generados por IA.

A partir de imágenes originales de productos como camisetas, pantalones y otras prendas, se desarrollaron workflows en ComfyUI para:

- colocar las prendas en modelos generados por IA
- modificar poses
- cambiar fondos y entornos
- generar imágenes más atractivas para presentación comercial

## Objetivo
El objetivo fue crear contenido visual tipo e-commerce / marketing para una marca que no disponía de fotografías con modelos.

## Herramientas utilizadas
- ComfyUI
- Generación de imágenes con IA en local
- Workflows personalizados para edición y transformación de imagen

## Contenido del repositorio
- `examples/`: ejemplos de artículos originales y resultados generados
- `workflows/`: archivos JSON de los workflows utilizados

## Resultados
El proyecto permitió convertir imágenes simples de producto en composiciones visuales más útiles para presentación de marca, catálogo y promoción online.
